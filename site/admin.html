PRODUCTION CHECKLIST

Connect a real database

The local preview runs without npm or third-party services. Before publishing your website, connect Firebase or Supabase for secure login, online content updates, image uploads and client inquiries.

  1. For Firebase: follow FIREBASE_SETUP_V5.md for config, Auth UID, Firestore Rules and Storage Rules.
  2. For Supabase: use the existing supabase/schema.sql and site/js/config.js.
  3. Verify admin sign-in, project CRUD, photo uploads and real inquiry submissions before going live.

Never place secret admin keys or service-account keys in frontend files. Hiding the /admin URL does not secure data; database policies do.
